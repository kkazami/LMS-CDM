# Agent skills and engineering orchestration

The authoritative workflow is [Engineering harness v2](../../.orchestra/harness/README.md).
See [assessment and redesign](harness-redesign.md) for inventory, failure analysis, decisions,
changed-file rationale and verification limits. The executable controller lives in scripts/harness.

Skills remain specialized capabilities. Keep impeccable for UI work, vercel-composition-patterns
for component architecture, and vercel-react-best-practices for React/Next.js performance.
Brandkit and high-end-visual-design are optional art-direction capabilities. Full-output-enforcement
is optional for exhaustive deliverables and cannot force unsafe full-file rewrites, gate changes
or early interruption. None substitutes for architecture adjudication, tests, independent security
review, code review or human approval. Actual skill source content is unchanged by this redesign.

Legacy planner/generator/evaluator files now point to the v2 roles. Historical sprint contracts,
evaluator logs and memory are retained as context; scores/checkmarks do not constitute release
or deployment evidence. No LMS feature from any existing implementation plan was implemented.
